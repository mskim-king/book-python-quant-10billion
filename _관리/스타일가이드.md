# 위키독스 원고 스타일 가이드 (비공개)

「파이썬으로 시작하는 실전 퀀트 투자」 원고를 쓸 때 지키는 규칙입니다. 위키독스 화면에서 읽기 좋고, 나중에 고치기 쉬운 형태를 목표로 합니다.

## 1. 페이지 뼈대

```markdown
<!--
**상태**: 🔵 검토 중
**분류**: 02. 프롬프트 기본기
**태그**: #프롬프트
**작성일**: 2026-11-21
-->
> 📅 **최종 확인**: 2026-11-21

(도입 1~2문장: 이 페이지를 읽으면 무엇을 할 수 있게 되는지)

[TOC]                       ← 소제목이 5개 이상인 긴 페이지에만

## 요약                     ← 3줄 이내, 바쁜 독자를 위한 결론
## (본문 소제목들)
## 실무 체크포인트           ← 체크리스트 [ ]
## 관련 페이지
```

- 본문에 `# 제목`(H1)을 쓰지 않습니다. 제목은 TOC.md 에서 가져옵니다.
- 소제목은 `##` → `###` 순서로만 내려갑니다. 단계를 건너뛰지 않습니다.
- 한 페이지는 화면 스크롤 3~5번 분량(약 1,500~3,000자)을 기준으로 합니다. 길어지면 페이지를 나눕니다.

## 2. 위키독스 전용 문법

| 문법 | 쓰임 | 사용 기준 |
|---|---|---|
| `[[TIP]]` … `[[/TIP]]` | 팁 상자 | 꼭 알아야 할 요령, 주의 사항. 한 페이지에 1~3개 |
| `[[TIP("제목")]]` … `[[/TIP]]` | 제목 있는 팁 상자 | "주의", "알아두기" 등 성격을 밝힐 때 |
| `[[SubPages]]` | 하위 페이지 목록 | 장(章) 대표 페이지 맨 아래 |
| `[TOC]` | 페이지 안 목차 | 소제목이 많은 긴 페이지 |

팁 상자 안에서는 위아래를 한 줄씩 비웁니다.

```markdown
[[TIP("주의")]]

AI가 알려 준 숫자·날짜·인용은 반드시 원문으로 확인합니다.

[[/TIP]]
```

| 장치 | 형식 | 목적 |

| 예시·코드 | ` ```text ` 또는 ` ```python ` 코드블록 | 복사해서 바로 사용 |

## 4. 문장

- 합니다체로 씁니다. 한 문장에는 한 가지 내용만 담습니다.
- 처음 나오는 영어 용어는 `한글(English)` 로 씁니다. 예: 프롬프트(Prompt), 환각(Hallucination).
- 특정 서비스 이름보다 유형("대화형 AI", "검색형 AI")으로 설명합니다. 서비스 이름이 필요하면 05장·09장·부록에 모읍니다.
- "항상", "절대" 같은 단정은 피하고 조건을 밝힙니다.
- 사실·수치는 출처를 남깁니다. 확인하지 못한 내용은 쓰지 않습니다.

## 5. 이미지

- 파일은 `assets/` 에 영문 kebab-case 이름으로 저장합니다. 예: `prompt-5-elements.png`
- 페이지에서는 `![설명](../assets/prompt-5-elements.png)`, README 에서는 `./assets/…` 경로를 씁니다.
- 화면 캡처에는 개인정보·계정 정보가 보이지 않게 가립니다.

## 6. 설명 이미지 만들기

- 설명 이미지는 `tools/diagrams.yaml` 에 글로 정의하고 `python tools/build_diagrams.py` 로 PNG 를 만듭니다.
- 모양(layout): `flow`(단계 흐름), `cards`(카드), `compare`(나쁜 예 → 좋은 예), `matrix`(2x2 판단표), `spectrum`(연속 스펙트럼), `triple`(관계 그래프), `stack`(계층).
- 색 테마는 `diagrams.yaml` 맨 위 `theme` 에서 책 전체를 한 번에 바꿉니다. 제목에서 `*강조*` 로 감싼 부분은 그라데이션으로 강조됩니다.
- 파일 이름: 장 대표 이미지는 `chNN-…png`, 페이지 안 이미지는 `pNN-N-…png`.
- 장 대표 이미지는 장 페이지의 첫 문단 바로 아래, 페이지 이미지는 관련 소제목 바로 아래에 넣습니다.
- 대체 텍스트(`![…]`)에는 이미지 내용을 한 문장으로 적습니다.
- 이미지 한 장에 담는 내용은 5단계·6칸 이내로 합니다.
- 필요한 것: Python(pyyaml), Node.js + Playwright, 한글 글꼴(Noto Sans CJK KR), 이모지 글꼴(Noto Color Emoji).
