**평균회귀**는 "평균에서 크게 벗어난 가격은 다시 평균으로 돌아온다"는 가정에 베팅합니다. 대표 지표는 **볼린저밴드**(이동평균 ± 표준편차 2배)입니다.

## 요약

- 규칙: 가격이 20일 평균보다 표준편차 2배 이상 낮으면(z < −2) 매수, 평균을 회복하면(z > 0) 매도.
- 가상 종목 B에서는 매수 후 보유(+21.7%)보다 못했습니다(−1.7%). 꾸준히 오르는 종목에서는 평균회귀가 불리합니다.
- 평균회귀는 '평균이 유지될 때'만 통합니다. 추세가 바뀌면 계속 물을 탈 위험이 있습니다.

## 코드

전체 코드는 `code/07_mean_reversion.py`에 있습니다.

```python
"""04-2. 평균회귀 — 볼린저밴드 (가상 데이터)"""
import pandas as pd
from sample_data import make_prices

price = make_prices()["B"]
ret = price.pct_change().fillna(0)
ma, sd = price.rolling(20).mean(), price.rolling(20).std()
z = (price - ma) / sd                         # 평균에서 표준편차 몇 개만큼 떨어졌나

pos = pd.Series(0.0, index=price.index)
holding = 0
for i, (d, zz) in enumerate(z.items()):
    if holding == 0 and zz < -2:              # 아래 밴드 이탈 → 매수
        holding = 1
    elif holding == 1 and zz > 0:             # 평균 회복 → 매도
        holding = 0
    pos.iloc[i] = holding
strat = pos.shift(1).fillna(0) * ret

eq_bh, eq_st = (1 + ret).cumprod(), (1 + strat).cumprod()
print(pd.DataFrame({
    "누적수익률": [eq_bh.iloc[-1] - 1, eq_st.iloc[-1] - 1],
    "MDD": [(eq_bh / eq_bh.cummax() - 1).min(), (eq_st / eq_st.cummax() - 1).min()],
    "보유비중": [1.0, pos.mean()],
}, index=["매수후보유", "볼린저 평균회귀"]).round(3))
print("\n진입 횟수:", int((pos.diff() == 1).sum()))
```

## 실행 결과

```text
          누적수익률    MDD   보유비중
매수후보유     0.217 -0.171  1.000
볼린저 평균회귀 -0.017 -0.137  0.218

진입 횟수: 12
```

## 해석

- 12번 진입했지만 누적수익률은 **−1.7%**로, 그냥 들고 있는 것(+21.7%)보다 나빴습니다.
- MDD는 조금 줄었지만(−17.1% → −13.7%), 보유 기간이 21.8%뿐이라 상승분을 대부분 놓쳤습니다.
- 평균회귀는 개별 종목보다 **함께 움직이는 두 종목의 차이**(04-3 페어 트레이딩)나 짧은 기간에서 더 자주 쓰입니다.

## 추세추종 vs 평균회귀

| 구분 | 추세추종 | 평균회귀 |
|---|---|---|
| 가정 | 움직임이 이어진다 | 움직임이 되돌아온다 |
| 잘 맞는 장 | 큰 추세장 | 횡보장 |
| 손익 모양 | 작은 손실 여러 번, 큰 이익 가끔 | 작은 이익 여러 번, 큰 손실 가끔 |
| 위험 | 횡보장에서 잦은 손실 | 추세가 바뀌면 손실 누적 |

> 모든 수치는 가상 데이터로 계산한 결과이며 투자 권유가 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다.
