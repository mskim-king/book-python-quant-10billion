백테스트 결과를 부풀리는 대표적인 착각이 두 가지 있습니다. **생존편향**(망한 종목을 빼고 계산)과 **미래참조편향**(그때는 몰랐던 정보를 사용)입니다. 둘 다 코드 한 줄 차이로 생깁니다.

## 요약

- **미래참조**: 같은 날 종가로 만든 신호로 같은 날 수익을 얻으면, 샤프지수가 0.59 → 18.6처럼 비현실적으로 커집니다.
- **생존편향**: 현재 상장 종목만 쓰면 평균이 부풀려집니다(02-4 예시: −29.6% → +14.0%).
- 결과가 너무 좋으면 먼저 **편향을 의심**하세요.

![샤프지수 18.6의 천재 전략?](../assets/p05-3-comic-lookahead.png)

## 미래참조편향 실험

전체 코드는 `code/12_biases.py`에 있습니다.

```python
"""05-3. 미래참조편향 — 같은 날 종가로 신호를 만들고 같은 날 수익을 먹으면 생기는 착시"""
import pandas as pd
from sample_data import make_prices
from importlib import import_module

eng = import_module("10_backtest_engine")
price = make_prices()["B"]
ret = price.pct_change().fillna(0)
signal = (ret > 0).astype(float)          # '오늘 올랐으면 보유' — 오늘이 끝나야 알 수 있는 정보

wrong = signal * ret                       # ❌ 신호를 같은 날 적용 (미래참조)
right = eng.backtest(price, signal)["net"] # ✅ 다음 날 적용
print(pd.DataFrame({"미래참조(잘못)": eng.report(wrong), "다음날 적용(올바름)": eng.report(right)}).T.round(3))
```

## 실행 결과

```text
              CAGR    변동성  샤프(무위험0)   MDD
미래참조(잘못)     1.652  0.089    18.605  0.00
다음날 적용(올바름)  0.064  0.110     0.587 -0.12
```

## 해석

- "오늘 올랐으면 보유"를 **같은 날** 적용하면, 오른 날만 골라 먹는 셈이라 MDD가 0, CAGR이 165%가 됩니다. 불가능한 결과입니다.
- 신호를 **다음 날** 적용하면 CAGR 6.4%, 샤프 0.59로 평범해집니다. 이것이 진짜 결과입니다.

## 자주 나오는 편향 정리

| 편향 | 예 | 막는 법 |
|---|---|---|
| 미래참조 | 오늘 종가 신호로 오늘 매매, 3월 공시 재무를 12월부터 사용 | 신호 `shift(1)`, 공시 접수일 기준 (02-3) |
| 생존편향 | 현재 상장 종목만으로 과거 검증 | 과거 시점의 전체 종목 목록 사용 (02-4) |
| 데이터 스누핑 | 수백 개 규칙을 시험하고 가장 좋은 것만 보고 | 검증 구간 분리, 시험 횟수 기록 (05-4) |
| 비용 무시 | 수수료·세금·슬리피지를 빼먹음 | 비용 넣기 (05-2) |

[[TIP("결과가 너무 좋다면")]]

샤프지수가 3을 넘거나 MDD가 거의 없다면 대부분 버그나 편향입니다. 날짜를 하루씩 밀어 보고, 결과가 크게 바뀌는지 확인하세요.

[[/TIP]]

> 모든 수치는 가상 데이터로 계산한 결과이며 투자 권유가 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다.
