> 📅 **최종 확인**: 2026-11-22

이 책의 예제를 따라 하려면 파이썬과 데이터 분석 라이브러리가 필요합니다. 이 페이지에서는 처음 하는 사람도 따라 할 수 있도록 분석 환경을 만드는 방법을 정리합니다.

## 요약

- 파이썬을 설치하고, 프로젝트마다 **가상환경**을 만들어 라이브러리를 관리합니다.
- 기본 라이브러리는 **numpy, pandas**입니다. 장이 진행되면서 필요한 라이브러리를 추가합니다.
- 책의 예제 코드는 저장소의 `code/` 폴더에 있고, 자동으로 실행 검사를 합니다.

![분석 환경 레벨업 지도](../assets/p01-4-quest-setup.png)

## 준비물

| 항목 | 설명 |
|---|---|
| 파이썬 | 3.10 이상 권장. python.org에서 설치 |
| 코드 편집기 | VS Code 등 익숙한 편집기 |
| 라이브러리 | numpy(수치 계산), pandas(표 데이터 처리) |
| 선택 | Jupyter Notebook (결과를 바로 보며 실습할 때 편리) |

## 설치 순서

### 1. 파이썬 설치 확인

```bash
python --version
```

`Python 3.10` 이상이 나오면 됩니다. 윈도우에서는 설치할 때 **"Add Python to PATH"**를 체크하세요.

### 2. 프로젝트 폴더와 가상환경 만들기

```bash
mkdir quant-study
cd quant-study
python -m venv .venv
```

가상환경을 켭니다.

```bash
# 윈도우
.venv\Scripts\activate

# 맥·리눅스
source .venv/bin/activate
```

### 3. 라이브러리 설치

```bash
pip install numpy pandas
```

### 4. 책 예제 실행해 보기

책 저장소의 `code/` 폴더를 받은 뒤 실행합니다.

```bash
pip install -r code/requirements.txt
python code/01_returns.py
```

01-2의 실행 결과와 같은 표가 나오면 준비가 끝난 것입니다.

[[TIP("왜 가상환경을 쓰나요?")]]

프로젝트마다 라이브러리 버전이 다를 수 있습니다. 가상환경을 쓰면 프로젝트끼리 서로 영향을 주지 않아서, "어제까지 되던 코드가 갑자기 안 돼요" 같은 문제를 줄일 수 있습니다.

[[/TIP]]

## 막혔을 때

| 증상 | 해결 |
|---|---|
| `python` 명령을 찾을 수 없음 | 윈도우는 `py` 명령을 시도하거나, PATH 설정 후 터미널 재시작 |
| `ModuleNotFoundError: pandas` | 가상환경을 켰는지 확인 후 `pip install pandas` |
| 오류 메시지를 모르겠음 | 오류 메시지 전체를 복사해 AI에게 물어보기 (『AI 300% 활용법』 05-4 참고) |
