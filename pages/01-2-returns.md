전략의 성과를 비교하려면 수익률을 정확히 계산할 수 있어야 합니다. 이 페이지에서는 퀀트 투자에서 자주 쓰는 네 가지 수익률을 파이썬으로 계산합니다.

## 요약

- **단순수익률**은 직관적이고, **로그수익률**은 기간별로 더할 수 있어 계산이 편합니다.
- 여러 기간의 성과는 **누적수익률**로, 기간이 다른 전략끼리는 **연평균 복리수익률(CAGR)**로 비교합니다.
- 일간 수익률의 단순 평균에 252를 곱한 값은 실제 성과와 다를 수 있습니다. 비교에는 CAGR을 씁니다.

## 개념

| 수익률 | 공식 | 쓰임 |
|---|---|---|
| 단순수익률 | (오늘 가격 ÷ 어제 가격) − 1 | 하루·한 달의 성과, 포트폴리오 수익률 계산 |
| 로그수익률 | ln(오늘 가격 ÷ 어제 가격) | 여러 기간을 더해서 계산, 통계 분석 |
| 누적수익률 | (1+r₁)(1+r₂)…(1+rₙ) − 1 | 전체 기간의 총 성과 |
| CAGR | (마지막 가격 ÷ 처음 가격)^(1/연수) − 1 | 기간이 다른 전략끼리 비교 |

[[TIP("알아두기")]]

1년 동안 주식시장이 열리는 날은 보통 약 **252일**로 계산합니다. 일간 값을 연간 값으로 바꿀 때 이 숫자를 씁니다.

[[/TIP]]

## 코드

전체 코드는 저장소의 `code/01_returns.py`에 있습니다. 예제는 실제 종목이 아닌 **가상의 주가 데이터**(종목 A, B, C, 약 3년)를 사용합니다.

```python
import numpy as np
from sample_data import make_prices   # 책 예제용 가상 주가

prices = make_prices()

# 1) 일간 단순수익률
simple = prices.pct_change().dropna()

# 2) 일간 로그수익률
log_ret = np.log(prices / prices.shift(1)).dropna()

# 3) 누적수익률
cumulative = (1 + simple).prod() - 1

# 4) 연평균 복리수익률(CAGR)
years = len(prices) / 252
cagr = (prices.iloc[-1] / prices.iloc[0]) ** (1 / years) - 1
```

## 해석과 주의점

- 가상 데이터에서 종목 C는 **기대수익률을 가장 높게** 설정했지만, 변동성도 가장 커서 이번 표본에서는 3년간 약 82% 손실이 났습니다. **기대수익률이 높아도 실제 결과는 크게 다를 수 있다**는 점을 보여 줍니다.
- 종목 A는 3년 누적 −16.7%, 연평균 −5.9%입니다. 누적수익률과 CAGR은 기간이 길수록 차이가 커지므로, 서로 다른 기간의 전략을 비교할 때는 CAGR을 씁니다.
- 실제 주가로 계산할 때는 **배당과 액면분할을 반영한 수정주가**를 써야 합니다. (02-4)
- 과거 성과가 미래 수익을 보장하지 않습니다.
