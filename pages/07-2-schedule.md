> 📅 **최종 확인**: 2026-11-25

자동매매는 **정해진 시간에 정해진 일을** 빠짐없이 해야 합니다. 이 페이지에서는 하루 일과를 시간표로 만들고, 장 운영시간과 휴장일을 고려해 실행하는 방법을 다룹니다.

## 요약

- 하루 흐름: 장 전 데이터 갱신 → 신호 계산 → 주문 → 체결 확인 → 장 후 기록.
- **휴장일**과 **장 운영시간 변경**(예: 연초 개장일)을 반영해야 합니다. 거래소 공지를 기준으로 합니다.
- 같은 주문이 두 번 나가지 않도록 '오늘 이미 실행했는가'를 기록합니다(중복 방지).

## 하루 시간표 예시 (월 리밸런싱 전략)

| 시간 | 할 일 | 실패 시 |
|---|---|---|
| 장 시작 전 | 전일 종가·재무 데이터 갱신, 데이터 점검 (02-4) | 매매 중단, 알림 |
| 장 시작 전 | 목표 비중 계산, 주문 목록 작성 | 매매 중단 |
| 장 중 | 분할 주문 (한 번에 다 사지 않기) | 미체결 주문 취소 |
| 장 마감 후 | 체결·잔고 확인, 목표와 차이 기록 | 다음 날 보정 |
| 장 마감 후 | 일일 리포트 저장·전송 (07-3) | 알림 |

> 정규장 시간과 휴장일은 한국거래소 공지를 확인해 코드의 설정값으로 관리하세요.

## 스케줄 실행 방법

| 방법 | 설명 | 적합 |
|---|---|---|
| cron (리눅스·맥) | 정해진 시각에 스크립트 실행 | 서버 1대 |
| 작업 스케줄러 (윈도우) | 윈도우 기본 기능 | 개인 PC |
| 파이썬 루프 + 시간 확인 | 프로그램이 계속 켜져 있음 | 실시간 감시가 필요할 때 |

```text
# cron 예: 평일 08:40에 데이터 갱신, 09:10에 주문 스크립트 실행
40 8 * * 1-5  /home/me/quant/.venv/bin/python /home/me/quant/update_data.py
10 9 * * 1-5  /home/me/quant/.venv/bin/python /home/me/quant/rebalance.py
```

## 중복 실행 막기 (예시)

```python
from pathlib import Path
from datetime import date

flag = Path(f"logs/rebalance_{date.today():%Y%m%d}.done")
if flag.exists():
    raise SystemExit("오늘은 이미 실행했습니다")
# ... 주문 실행 ...
flag.touch()     # 성공했을 때만 표시
```

[[TIP("휴장일 처리")]]

스크립트 첫 줄에서 **오늘이 거래일인지** 확인하세요. 휴장일 목록은 매년 거래소 공지로 갱신합니다.

[[/TIP]]
