자동매매는 증권사가 제공하는 **API**로 주문을 보냅니다. 이 페이지에서는 국내 증권사 API의 종류와 연결 흐름, 그리고 안전한 연결을 위한 원칙을 정리합니다. 실제 주문 코드는 계좌·인증키가 필요하므로 **모의투자**에서 먼저 시험하세요.

## 요약

- 최근에는 운영체제와 상관없이 쓸 수 있는 **REST API**(HTTP 요청)가 늘었습니다. 키움증권은 2025년 3월 REST API를 출시했습니다.
- 공통 흐름: 앱키·시크릿 발급 → **접근토큰** 받기 → 시세 조회·주문 → 실시간은 WebSocket.
- 인증키는 **환경변수·비밀 관리 도구**에 두고, 코드나 저장소에 절대 올리지 않습니다.

## 국내 증권사 API 유형

| 유형 | 방식 | 특징 |
|---|---|---|
| REST API | HTTP 요청·응답, 실시간은 WebSocket | 윈도우·맥·리눅스 모두 가능, 클라우드 서버에서 실행하기 좋음 |
| 전용 모듈(OCX/COM 등) | 증권사 프로그램을 설치하고 연결 | 주로 윈도우 전용, 오래된 자료가 많음 |

> 제공 기능·호출 한도·지원 상품은 증권사마다 다르고 자주 바뀝니다. 각 증권사 개발자 센터의 최신 문서를 기준으로 하세요.

## 연결 흐름 (REST API 공통 모양)

```text
① 개발자 센터 가입 → 앱키(App Key)·시크릿(App Secret) 발급
② 앱키·시크릿으로 접근토큰 요청 (유효기간 있음)
③ 토큰을 헤더에 넣어 시세·잔고 조회
④ 주문 요청 (모의투자 서버로 먼저!)
⑤ 실시간 시세·체결 알림은 WebSocket으로 수신
```

## 안전한 연결을 위한 코드 원칙 (예시)

아래는 구조를 보여 주는 예시이며, 실제 주소·필드 이름은 증권사 문서를 따르세요. 계좌가 필요해 실행하지 않았습니다.

```python
import os

APP_KEY = os.environ["BROKER_APP_KEY"]        # 키는 환경변수에서 읽기 (코드에 쓰지 않기)
APP_SECRET = os.environ["BROKER_APP_SECRET"]
BASE_URL = os.environ.get("BROKER_URL")      # 모의투자 주소로 시작

MAX_ORDER_KRW = 1_000_000                     # 1회 주문 상한 — 버그가 나도 피해를 제한

def place_order(code: str, qty: int, price: int):
    amount = qty * price
    if amount > MAX_ORDER_KRW:
        raise ValueError(f"주문 금액 {amount:,}원이 상한을 넘었습니다")
    # ... 증권사 문서에 맞춰 요청 ...
```

[[TIP("처음 시작할 때")]]

1. **모의투자** 계좌로 최소 몇 주 이상 돌려 보세요.
2. 실계좌는 **아주 작은 금액**으로 시작하고, 1회·1일 주문 상한을 코드에 넣으세요.
3. 앱키·시크릿·계좌번호는 `.env` 파일에 두고 `.gitignore`에 추가하세요.
