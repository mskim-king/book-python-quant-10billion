시간이 지나면 오른 자산의 비중이 커지고, 처음 정한 위험 수준에서 벗어납니다. **리밸런싱**은 비중을 목표로 되돌리는 일입니다. 이 페이지에서 60/40 포트폴리오로 네 가지 리밸런싱 방식을 비교합니다.

## 요약

- 리밸런싱을 **안 하면** 주식 비중이 60% → 78%로 불어나 변동성과 MDD가 커졌습니다.
- 분기·월·밴드(±5%p) 방식은 위험을 목표 근처로 유지했고, 그중 **밴드 방식**이 매매가 가장 적었습니다.
- 리밸런싱의 목적은 수익을 높이는 것보다 **위험을 처음 계획대로 유지**하는 것입니다.

![리밸런싱 안 하면 더 벌잖아요?](../assets/p06-2-chat-rebalance.png)

## 코드

전체 코드는 `code/15_rebalance.py`에 있습니다.

```python
"""06-2. 리밸런싱 — 60/40 포트폴리오를 안 함·분기·월·밴드(±5%p) 방식으로 비교"""
import numpy as np
import pandas as pd
from sample_data import make_assets

px = make_assets()[["주식", "채권"]]
ret = px.pct_change().dropna()
target = np.array([0.6, 0.4])

def run(rule):
    w, out, trades, prev = target.copy(), [], 0.0, ret.index[0]
    for d, r in ret.iterrows():
        need = (rule == "월" and d.month != prev.month) or \
               (rule == "분기" and d.month != prev.month and d.month in (1, 4, 7, 10)) or \
               (rule == "밴드" and abs(w[0] - target[0]) > 0.05)
        if need:
            trades += np.abs(w - target).sum() / 2; w = target.copy()
        out.append((w * r.values).sum())
        w = w * (1 + r.values); w /= w.sum(); prev = d
    s = pd.Series(out, index=ret.index); eq = (1 + s).cumprod()
    return {"CAGR": eq.iloc[-1] ** (252 / len(s)) - 1, "변동성": s.std() * np.sqrt(252),
            "MDD": (eq / eq.cummax() - 1).min(), "누적매매비율": trades, "최종 주식비중": w[0]}

print(pd.DataFrame({k: run(k) for k in ["안 함", "분기", "월", "밴드"]}).T.round(3))
```

## 실행 결과

```text
      CAGR    변동성    MDD  누적매매비율  최종 주식비중
안 함  0.112  0.121 -0.191   0.000    0.780
분기   0.100  0.105 -0.174   0.394    0.592
월    0.099  0.104 -0.174   0.689    0.592
밴드   0.101  0.105 -0.171   0.308    0.593
```

## 해석

- '안 함'은 CAGR이 가장 높지만(11.2%), 그 이유는 주식 비중이 78%까지 불어났기 때문입니다. 위험(변동성 12.1%, MDD −19.1%)도 함께 커졌습니다. 같은 위험이 아니라 **다른 포트폴리오**가 된 것입니다.
- 밴드 방식은 분기 방식과 비슷한 위험을 유지하면서 누적 매매비율이 가장 작았습니다(0.308). 필요할 때만 매매하기 때문입니다.

## 방식 선택 가이드

| 방식 | 규칙 | 장점 | 단점 |
|---|---|---|---|
| 정기(월·분기) | 정해진 날 목표 비중으로 | 단순, 자동화 쉬움 | 필요 없을 때도 매매 |
| 밴드 | 목표에서 ±5%p 벗어나면 | 매매 최소화 | 매일 점검 필요 |
| 현금흐름 이용 | 입금·배당으로 부족한 자산을 삼 | 세금·비용 절약 | 큰 이탈은 못 막음 |

> 모든 수치는 가상 데이터로 계산한 결과이며 투자 권유가 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다.
