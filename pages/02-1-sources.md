> 📅 **최종 확인**: 2026-11-25

퀀트 투자는 데이터에서 시작합니다. 좋은 전략도 데이터가 틀리면 결과가 모두 틀립니다. 이 페이지에서는 국내·해외 투자 데이터를 어디서 구하는지, 각 소스를 쓸 때 무엇을 조심해야 하는지 정리합니다.

## 요약

- 국내 주가는 **한국거래소(KRX) 정보데이터시스템**, 재무·공시는 **금융감독원 OpenDART**가 1차 소스입니다.
- 파이썬에서는 `pykrx`, `FinanceDataReader` 같은 오픈소스 라이브러리로 편하게 받을 수 있지만, **비공식 도구**라 사양이 바뀔 수 있습니다.
- 어떤 소스든 **수정주가 여부, 상장폐지 종목 포함 여부, 데이터 공개 시점**을 먼저 확인합니다.

![데이터는 어디서 받아요?](../assets/p02-1-chat-sources.png)

## 데이터 소스 지도

| 데이터 | 1차(공식) 소스 | 파이썬에서 쓰는 방법 | 주의할 점 |
|---|---|---|---|
| 국내 주가·거래량 | 한국거래소 정보데이터시스템 (data.krx.co.kr) | `pykrx`, `FinanceDataReader` | 일부 기능은 KRX 회원 로그인 필요(라이브러리 문서 확인) |
| 국내 재무제표·공시 | 금융감독원 OpenDART (opendart.fss.or.kr) | OpenDART API(무료 인증키), `OpenDartReader` | 회계기간이 아니라 **공시 접수일** 기준으로 써야 함 (02-3) |
| 공공 금융 데이터 | 공공데이터포털 (data.go.kr) 금융위원회 시세 API | REST API | 하루 지연 데이터, 호출 한도 |
| 금리·환율·경제지표 | 한국은행 경제통계시스템 ECOS | ECOS Open API | 지표마다 발표 주기가 다름 |
| 해외 주가 | 거래소·데이터 업체 | `yfinance`(비공식) | 비공식 수집 도구, 상업적 이용 조건 확인 |
| 해외 경제지표 | 미국 세인트루이스 연준 FRED | FRED API | 사후 수정(revision)되는 지표가 있음 |

## 소스를 고르는 기준

1. **정확성**: 공식 소스(거래소·감독원·중앙은행)를 우선합니다. 라이브러리는 이 소스를 대신 가져오는 도구입니다.
2. **시점 정보**: 그 숫자가 **언제 공개되었는지** 알 수 있어야 백테스트에서 미래 정보를 쓰지 않습니다.
3. **생존편향**: 상장폐지된 종목까지 포함하는지 확인합니다. 현재 상장 종목만 받으면 결과가 부풀려집니다 (02-4, 05-3).
4. **이용 조건**: 개인 학습용과 상업적 이용 조건이 다를 수 있습니다. 각 서비스의 약관을 확인합니다.

[[TIP("처음 시작한다면")]]

이 책의 예제는 `code/sample_data.py`의 **가상 데이터**로 바로 실행됩니다. 코드 흐름을 먼저 익히고, 익숙해지면 같은 코드에 실제 데이터를 넣어 보세요. 실제 데이터를 쓸 때는 결과가 가상 데이터와 전혀 다를 수 있습니다.

[[/TIP]]

## 예시: 소스별 '받을 수 있는 것'

```text
전략: 저PBR + 모멘텀 멀티팩터 (03장)
필요한 데이터
  ├─ 월말 수정종가 ........ KRX(pykrx 등)          → 모멘텀, 수익률
  ├─ 자본총계·당기순이익 ... OpenDART 재무제표       → PBR, ROE
  ├─ 공시 접수일 .......... OpenDART 공시목록        → 데이터 사용 가능 시점
  └─ 상장폐지 이력 ........ KRX 상장폐지 현황        → 생존편향 제거
```
