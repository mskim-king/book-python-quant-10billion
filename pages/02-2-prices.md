주가 데이터는 퀀트의 기본 재료입니다. 이 페이지에서는 실제 데이터를 받는 코드 모양과, 받은 데이터를 **분석하기 좋은 형태**로 정리하는 방법을 배웁니다.

## 요약

- 실제 수집 코드는 `pykrx`·`FinanceDataReader` 등으로 몇 줄이면 됩니다 (네트워크와 라이브러리 필요).
- 받은 데이터는 **날짜 인덱스 × 종목 열**의 '넓은 표'로 정리하면 수익률 계산이 쉬워집니다.
- 수정주가인지, 거래가 없는 날을 어떻게 표시했는지 꼭 확인합니다.

## 실제 데이터 받기 (예시 코드)

아래 코드는 라이브러리 설치와 인터넷 연결이 필요해 이 책의 자동 검증에서는 실행하지 않았습니다. 사용법은 각 라이브러리 문서를 기준으로 확인하세요.

```python
# pip install finance-datareader
import FinanceDataReader as fdr

# 종목코드와 기간을 넣으면 일별 시가·고가·저가·종가·거래량 표를 돌려줍니다
df = fdr.DataReader("005930", "2024-01-01", "2024-12-31")
print(df.tail())
```

## 분석하기 좋은 형태로 정리하기

여러 종목을 받으면 종목마다 표가 따로 생깁니다. 종가만 모아 **넓은 표(날짜 × 종목)**로 만들면 수익률을 한 번에 계산할 수 있습니다.

```python
import pandas as pd

def to_wide(frames: dict) -> pd.DataFrame:
    # frames: {"종목코드": 일별 데이터 표}
    return pd.DataFrame({code: df["Close"] for code, df in frames.items()}).sort_index()
```

이 책의 예제는 같은 모양의 가상 데이터(`make_prices()`)를 씁니다. 01-2의 결과에서 앞 3일을 보면 다음과 같습니다.

## 받은 뒤 꼭 확인할 것

| 확인 | 방법 | 왜 |
|---|---|---|
| 수정주가인가 | 분할·배당이 있던 날 수익률이 비정상적으로 큰지 확인 | 원주가면 가짜 급락이 생김 (02-4) |
| 빈 날짜 | `df.isna().sum()` | 거래정지·상장 전 기간 |
| 중복 날짜 | `df.index.duplicated().sum()` | 수집 오류 |
| 이상치 | 일간 수익률이 ±30%를 넘는 날 목록 | 가격제한폭(±30%)을 넘으면 오류 의심 |
