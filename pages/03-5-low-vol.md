**저변동성 팩터**는 "덜 흔들리는 주식이 위험에 비해 오히려 나은 성과를 냈다"는 관찰(저변동성 이상현상)을 이용합니다.

## 요약

- 점수 = 최근 24개월 월간 수익률 표준편차가 **낮을수록** 높음.
- 가상 데이터 검증: 연 9.6%, 위험대비 1.126으로 단일 팩터 중 가장 좋았습니다(가정이 반영된 결과).
- 하락장 방어에 강하지만, 급등장에서는 덜 오릅니다.

## 계산

```python
low_vol = zscore(-monthly.loc[:t].tail(24).std())   # 최근 24개월 변동성, 낮을수록 점수↑
```

```text
      월평균 차이(상위-하위)    연환산  플러스인 달 비율  변동성(연)  위험대비(차이/변동성)
저변동성          0.008  0.096      0.642   0.085         1.126
```

## 왜 이런 현상이 생길까 (알려진 설명)

| 설명 | 내용 |
|---|---|
| 레버리지 제약 | 빚을 내기 어려운 투자자가 고변동 주식을 비싸게 사서 수익을 높이려 함 |
| 복권 선호 | 크게 오를 가능성에 기대 고변동 주식을 과하게 삼 |
| 기관 벤치마크 | 시장 대비 성과로 평가받는 운용사는 저변동 주식을 덜 담음 |

[[TIP("주의")]]

저변동성 종목은 특정 업종(유틸리티·통신 등)에 몰리기 쉽습니다. 업종 비중을 함께 확인하세요.

[[/TIP]]

> 모든 수치는 `code/sample_data.py`의 **가상 데이터** 결과입니다. 가상 데이터는 저PBR·고ROE·저변동성 종목에 작은 초과수익을 주도록 **가정해서 만든 것**이므로, 실제 시장에서 같은 결과가 나온다는 뜻이 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다.
