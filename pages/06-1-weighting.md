같은 종목을 골라도 **얼마씩 담느냐**에 따라 결과가 달라집니다. 이 페이지에서는 동일비중, 변동성 역가중, 최소분산 세 가지 방법으로 비중을 정하고, 앞 3년으로 계산한 비중이 뒤 2년에도 위험을 잘 맞추는지 확인합니다.

## 요약

- **동일비중**: 예측 없이 똑같이. **변동성 역가중**: 덜 흔들리는 자산에 더. **최소분산**: 공분산을 이용해 전체 변동성이 가장 작게.
- 가상 데이터에서 예상 변동성과 검증 구간의 실현 변동성이 거의 같았습니다(예: 6.0% vs 6.1%).
- 동일비중이어도 주식이 전체 위험의 **51.8%**를 차지했습니다. '돈의 비중'과 '위험의 비중'은 다릅니다.

## 코드

전체 코드는 `code/14_weighting.py`에 있습니다.

```python
"""06-1. 비중 결정 — 동일비중, 변동성 역가중, 최소분산 (가상 데이터)"""
import numpy as np
import pandas as pd
from sample_data import make_assets

ret = make_assets().pct_change().dropna()
train, test = ret.iloc[:756], ret.iloc[756:]          # 앞 3년으로 비중 계산, 뒤 2년에 적용
cov = train.cov().values * 252
n = len(train.columns)

w_eq = np.ones(n) / n
w_iv = (1 / np.sqrt(np.diag(cov))); w_iv /= w_iv.sum()
inv = np.linalg.inv(cov); w_mv = inv @ np.ones(n); w_mv /= w_mv.sum()   # 최소분산(공매도 허용 공식)

def risk_contrib(w):
    port_var = w @ cov @ w
    return w * (cov @ w) / port_var                    # 각 자산이 전체 위험에서 차지하는 비율

rows = {}
for name, w in {"동일비중": w_eq, "변동성역가중": w_iv, "최소분산": w_mv}.items():
    r = test.values @ w
    rows[name] = dict(zip([f"비중_{c}" for c in ret.columns], w.round(3)),
                      **{"예상변동성": np.sqrt(w @ cov @ w), "실현변동성(검증)": r.std() * np.sqrt(252),
                         "주식 위험기여": risk_contrib(w)[0]})
print(pd.DataFrame(rows).T.round(3))
```

## 해석

- **최소분산**은 변동성이 가장 낮은 채권에 85%를 몰았습니다. 변동성은 가장 낮지만(5.0%), 한 자산에 쏠리는 단점이 있습니다.
- **위험기여**를 보면, 동일비중에서 주식은 돈으로는 33%지만 위험으로는 52%를 차지합니다. 위험을 고르게 나누고 싶다면 변동성 역가중이나 위험 균형을 씁니다.
- 공분산은 과거 추정치라 바뀝니다. 이 예제의 최소분산 공식은 **공매도(음수 비중)도 허용**하는 공식이므로, 실전에서는 비중 하한(0 이상)을 두는 최적화를 씁니다.

## 방법 비교

| 방법 | 필요한 정보 | 장점 | 단점 |
|---|---|---|---|
| 동일비중 | 없음 | 단순, 추정 오류 없음 | 고변동 자산이 위험을 지배 |
| 변동성 역가중 | 각 자산 변동성 | 위험을 대략 고르게 | 상관관계 무시 |
| 최소분산 | 공분산 행렬 | 전체 변동성 최소 | 쏠림, 추정 오류에 민감 |

> 모든 수치는 가상 데이터로 계산한 결과이며 투자 권유가 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다.
