가치·퀄리티 팩터는 재무제표에서 나옵니다. 국내 상장사 재무제표는 금융감독원 **OpenDART API**로 무료로 받을 수 있습니다. 가장 중요한 주의점은 **"언제 알 수 있었던 숫자인가"**입니다.

## 요약

- OpenDART에서 무료 인증키를 받아 `fnlttSinglAcntAll`(단일회사 전체 재무제표)로 재무제표를 받습니다.
- 보고서 코드: 1분기 `11013`, 반기 `11012`, 3분기 `11014`, 사업보고서 `11011` / 연결 `CFS`, 개별 `OFS`.
- 백테스트에는 회계기간 말일이 아니라 **공시 접수일 이후**에만 그 숫자를 써야 합니다.

![2024년 실적, 언제부터 쓸 수 있어요?](../assets/p02-3-chat-timing.png)

## OpenDART로 재무제표 받기 (예시 코드)

인증키가 필요해 이 책의 자동 검증에서는 실행하지 않았습니다. 인증키는 환경변수에 넣고 코드에 직접 쓰지 마세요.

```python
import os, requests

params = {
    "crtfc_key": os.environ["DART_API_KEY"],  # 40자리 인증키 (코드에 직접 쓰지 않기)
    "corp_code": "00126380",                  # 회사 고유번호(8자리) — corpCode.xml에서 조회
    "bsns_year": "2024",
    "reprt_code": "11011",                    # 사업보고서
    "fs_div": "CFS",                          # 연결재무제표
}
r = requests.get("https://opendart.fss.or.kr/api/fnlttSinglAcntAll.json", params=params, timeout=30)
data = r.json()
print(data["status"])        # "000"이면 정상, "020"이면 호출 한도 초과
```

## 팩터에 필요한 항목

| 팩터 | 필요한 항목 | 계산 |
|---|---|---|
| PBR (가치) | 자본총계(지배주주) | 시가총액 ÷ 자본총계 |
| PER (가치) | 당기순이익(지배주주) | 시가총액 ÷ 당기순이익 |
| ROE (퀄리티) | 당기순이익, 자본총계 | 당기순이익 ÷ 평균 자본총계 |
| 부채비율 (퀄리티) | 부채총계, 자본총계 | 부채총계 ÷ 자본총계 |

## 가장 흔한 실수: 미래 정보 사용

```text
❌ 2024년 사업보고서 숫자를 2024-12-31부터 사용
   → 실제로는 2025년 3월 공시 → 백테스트가 석 달 먼저 '미래'를 앎

✅ 공시목록(list.json)의 접수일(rcept_dt)을 함께 저장
   → 접수일 다음 거래일부터 사용
```

[[TIP("재무 데이터 저장 팁")]]

재무 숫자 옆에 **접수일**과 **정정 여부**를 함께 저장하세요. 정정 공시가 나오면 숫자가 바뀌는데, 백테스트에서는 '그때 알 수 있었던 원래 숫자'를 써야 합니다.

[[/TIP]]
