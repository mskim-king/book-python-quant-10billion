**추세추종**은 "오르는 것을 사고, 내리는 것을 판다"는 전략입니다. 가장 단순한 형태는 짧은 이동평균이 긴 이동평균 위에 있을 때만 보유하는 **이동평균 교차**입니다.

## 요약

- 규칙: 20일 평균 > 120일 평균이면 보유, 아니면 현금. 신호는 **다음 날** 적용합니다.
- 가상 데이터의 크게 하락한 종목 C에서 MDD가 −85.2% → −22.9%로 줄었습니다.
- 대신 상승장에서는 늦게 타고 일찍 내려 수익을 놓치며, 횡보장에서는 잦은 손실이 납니다.

## 코드

전체 코드는 `code/06_trend.py`에 있습니다.

```python
"""04-1. 추세추종 — 이동평균 교차 전략 (가상 데이터)"""
import numpy as np
import pandas as pd
from sample_data import make_prices

price = make_prices()["C"]
ret = price.pct_change().fillna(0)

short, long = price.rolling(20).mean(), price.rolling(120).mean()
signal = (short > long).astype(int)          # 단기선이 장기선 위면 보유(1), 아니면 현금(0)
position = signal.shift(1).fillna(0)         # 오늘 신호로 '내일' 매매 → 미래참조 방지
strat = position * ret

def stats(r: pd.Series) -> dict:
    eq = (1 + r).cumprod()
    years = len(r) / 252
    return {"누적수익률": eq.iloc[-1] - 1, "CAGR": eq.iloc[-1] ** (1 / years) - 1,
            "MDD": (eq / eq.cummax() - 1).min(), "보유비중": None}

res = pd.DataFrame({"매수후보유": stats(ret), "이동평균교차": stats(strat)}).T
res.loc["매수후보유", "보유비중"] = 1.0
res.loc["이동평균교차", "보유비중"] = position.mean()
print(res.astype(float).round(3))
print("\n매매 횟수:", int(position.diff().abs().sum()))
```

## 실행 결과

```text
        누적수익률   CAGR    MDD   보유비중
매수후보유  -0.819 -0.434 -0.852  1.000
이동평균교차 -0.088 -0.030 -0.229  0.188

매매 횟수: 4
```

## 해석

- 종목 C는 가상 기간 동안 **−81.9%** 떨어졌습니다. 이동평균 교차는 전체 기간의 18.8%만 보유해 손실을 **−8.8%**로 줄였습니다.
- 추세추종의 진짜 가치는 수익률보다 **큰 하락을 피하는 것(MDD −22.9%)**에 있습니다.
- 반대로 꾸준히 오르는 종목에서는 매수 후 보유보다 수익이 낮은 경우가 많습니다. 하나의 결과로 일반화하지 마세요.

## 신호를 하루 늦게 쓰는 이유

```python
position = signal.shift(1)   # 오늘 종가로 만든 신호는 내일부터 적용
```

오늘 종가를 보고 만든 신호로 오늘 수익을 얻을 수는 없습니다. `shift(1)`을 빼면 결과가 비현실적으로 좋아집니다 (05-3).

> 모든 수치는 가상 데이터로 계산한 결과이며 투자 권유가 아닙니다. 과거 성과는 미래 수익을 보장하지 않습니다.
